// できること
- テーブルの作成
- 行の挿入
- 行のクエリ
- セカンダリインデックス
  

// できないこと
- マルチスレッド
  - 同時に一つのクエリしか実行できない
- トランザクション
  - 同時に1つのクエ入りしか実行できないので、必要ない
- リカバリ
  - 途中でクラッシュした時に、実行中のトランザクションをロールバックする機能はない
- 複数のテーブル
- JOIN

ディスク上のデータ構造は、B+Treeのみ


// 実装すること
- クエリエクゼキュータ
- アクセスメソッド
- バッファプールマネージャ
- ディスクマネージャ
(構文解析器、クエリプランナ&実行計画は、実装しない)
